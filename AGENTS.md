# AGENTS.md

## Контекст

Перед существенными изменениями изучай:

- `context/hackaton_context.md` — официальное ТЗ и критерии;
- `context/data_context.md` — полученные данные и их статус;
- `context/feature.md` — дополнительные функции и порядок их реализации.

## Приоритет проекта

1. Достоверность распознавания.
2. Дополнительная post-search функция.
3. Архитектура, дизайн и скорость.

## Рабочий цикл

```text
data audit
→ baseline
→ evaluation
→ error analysis
→ hypothesis
→ experiment
→ evaluation
```

## Правила

- Не выдумывать требования; неизвестные форматы, метрики и ограничения считать неизвестными.
- Не начинать fine-tuning до проверки baseline.
- Не добавлять сложную инфраструктуру без необходимости.
- Не менять raw data.
- Любое улучшение подтверждать сопоставимыми метриками на одном split.
- Разрабатывать поэтапно: не реализовывать все дополнительные функции одновременно.
