# My Wine — распознавание вина по этикетке

Локальное desktop web-приложение для хакатона «Своё Вино». По фотографии
этикетки проект ищет товар в локальном каталоге и поддерживает контракт
проверки организаторов: `POST /api/predict` → `{"slug":"wine-slug"}`.

## Перед запуском

Откройте [пошаговую инструкцию запуска и проверки](web/README.md). Важно:
чистого `git clone` **недостаточно** для старта. Каталоговые фото, выбранный
LoRA-чекпоинт и согласованные с ним кэши исключены из Git. Их нужно получить
вместе с проектом и распаковать в корень репозитория с сохранением путей.
Готовность этих файлов проверяет команда:

```bash
python scripts/check_demo_assets.py
```

Если она сообщает об отсутствующих файлах, сервер не запустится. Инструкция
содержит точный список для передачи assets, установку зависимостей, запуск,
API smoke check и ручной сценарий проверки UI.

## Что увидят проверяющие

- распознавание этикетки и подсказку повторной съёмки при слабых сигналах;
- карточку вина с данными каталога и, если доступен сайт, дополнительными
  характеристиками с официальной страницы;
- Match for You по оценкам пользователя, последовательное сравнение двух вин
  и личную коллекцию в local storage браузера.

Это desktop web-интерфейс без мобильной адаптации. Match for You требует не
менее пяти оценённых вин. Сайт и локальный inference работают независимо:
доступность vino-svoe.ru влияет на дополнительные поля карточек, но не на поиск.

## Измеренные результаты

Локальный серийный прогон на 100 каталоговых фото после прогрева, на RTX 4060:
`p50=304 ms`, `p95=1,117 ms`, `p99=1,237 ms`, `max=1,484 ms`; 100/100 ответов
заняли меньше 3 секунд. На этих эталонных изображениях было 97 точных
`found`, 3 `retry` и 0 неверных `found`. Это результат одного оборудования и
фиксированной выборки, а не гарантия SLA для другого компьютера, параллельной
нагрузки или реальных фотографий. Подробности: [отчёт замера](reports/runtime_latency_sla_100_20260926_000314.md).

Новый набор из 100 полевых изображений пока не имеет проверенной разметки
slug/no-match. Внутренние synthetic/dev метрики не являются результатом на
закрытом наборе организаторов и не должны подаваться как такая оценка.
