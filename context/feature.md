# Дополнительные функции

Функции реализуются **СТРОГО ПОЭТАПНО**. Нельзя одновременно реализовывать несколько дополнительных функций. Порядок приоритетов:

1. Smart Retry
2. Match for You
3. Compare
4. Menu Scanner
5. Location / Store alternatives

## 1. Smart Retry

Поведение зависит от уверенности результата, но не должно противоречить основному UX ТЗ, в котором предполагается одна финальная карточка.

- **Высокая уверенность:** показать одну финальную карточку вина.
- **Недостаточно данных:** предложить переснять фото с конкретной инструкцией, например:
  - этикетка слишком далеко;
  - на этикетке блик;
  - не виден год;
  - сфотографируйте центральную часть ближе;
  - если сфотографирован баркод вместо этикетки, просканируйте именно этикетку.
- Похожие варианты не должны становиться основным экраном выбора.
- Если вина нет в каталоге, можно показывать аналоги; это отдельный сценарий, поддерживаемый ТЗ.

## 2. Match for You

Рейтинг вина с учётом предпочтений пользователя.

## 3. Compare

Сравнение бутылок на изображении. Допустим также последовательный скан с возможностью запоминать вина по нажатию.

## 4. Menu Scanner

Сканирование меню ресторана с последующим сравнением с метриками сайта и рекомендацией того, что лучше подойдёт к ужину или заказу.

## 5. Location / Store alternatives

Определение местоположения пользователя на карте, определение магазина и предложение альтернатив, доступных в этом магазине. Функция сильно зависит от наличия данных магазина. Альтернативы можно фильтровать по предпочтениям пользователя: цена, цена/качество и качество.

Новые дополнительные функции без необходимости не добавлять.
